# Sicherheit

Bitte melde sicherheitsrelevante Probleme nicht öffentlich als Issue, wenn sie
eine ungewollte Energieaktion, Geheimnisse oder lokale Daten betreffen.

Bis ein dedizierter privater Meldeweg eingerichtet ist, beschreibe das Problem
im privaten Kontaktweg des Repository-Eigentümers und füge keine Geheimnisse,
Tokens oder persönlichen Laufzeitdaten bei.

Der Wächter ist fail-closed gedacht: unklare Herdr-Zustände dürfen keinen
automatischen Abschluss auslösen. Änderungen an diesem Vertrag brauchen
Tests für Beobachtung, Abbruch, Warnung und Wiederaufnahme.
